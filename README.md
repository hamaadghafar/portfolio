# Hamaad Ghafar · Portfolio

Personal portfolio of **Hamaad Ghafar**, DevOps & Site Reliability Engineer (Kubernetes · Docker · CI/CD · AWS · Azure · F5 · Linux).

Built with React, TypeScript, Vite, styled-components and Framer Motion. Deployed on Netlify.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Editing content

All text lives in [`src/data/profile.ts`](src/data/profile.ts). The résumé download is served from `public/Hamaad_Ghafar_Resume.pdf`.
